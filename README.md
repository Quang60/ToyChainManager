# ToyChainManager

Đồ án cuối kỳ môn Cơ sở dữ liệu nâng cao. Dự án xây dựng hệ thống quản lý chuỗi cửa hàng đồ chơi, sử dụng PostgreSQL và MongoDB để tìm hiểu cách tổ chức dữ liệu có cấu trúc, bán cấu trúc và phi cấu trúc, cũng như cách hợp nhất dữ liệu trong hệ thống phân tán.

## Cấu trúc dự án

| Đường dẫn | Nội dung |
| --- | --- |
| `src/` | Mã nguồn của hệ thống |
| `docs/` | Tài liệu phân tích, thiết kế cơ sở dữ liệu và kiến trúc phân tán |
| `demo/` | Dữ liệu mẫu và kịch bản minh họa |
| `requirements.txt` | Danh sách thư viện Python cần cài đặt |

Repo đang ở bước khởi tạo. Nhóm sẽ bổ sung hướng dẫn chạy cùng với chức năng đầu tiên.
